¿Qué es el Planning de Fidelización?

Herramienta web interna para gestionar la actividad comercial de visitas a clientes. Planifica automáticamente las rutas semanales más eficientes, genera el planning en Excel con formato profesional, registra el resultado de cada visita y visualiza toda la actividad en un dashboard en tiempo real.

El sistema toma como punto de partida la base de clientes de la empresa, aplica un algoritmo propio de optimización de rutas y calcula qué clientes visitar cada día, en qué orden y con qué tiempos de desplazamiento reales. El resultado es un planning semanal listo para imprimir o compartir.

Tres pilares del sistema
PLANNING

Rutas optimizadas

Calcula automáticamente la ruta óptima de visitas semanales a partir de los clientes, agrupándolos por zona geográfica y respetando la jornada laboral.

NOTAS

Registro de visitas

Registra el resultado de cada visita: realizada, pospuesta o no interesado, con fecha y observaciones por cliente.

DASHBOARD

Visibilidad comercial

KPIs, agenda del día con datepicker, distribución de estados y evolución semanal de la actividad — todo de un vistazo.

Cómo se calcula el planning

El planning no se genera manualmente. Al pulsar el botón en la aplicación, se lanza automáticamente un proceso en la nube que aplica un algoritmo propio de optimización de rutas en varios pasos. El resultado se guarda directamente en la base de datos y queda disponible en la app al instante.

Punto de partida — datos de entrada
  • Base de clientes: nombre, dirección, código postal y municipio de cada cliente a visitar
  • Parámetros operativos: hora de inicio de jornada, duración media de cada reunión (minutos), tiempo de aparcamiento, radio máximo para ir andando entre visitas y horas máximas por día
  • Festivos del País Vasco: el sistema descarta automáticamente los días festivos del planning
  • Punto base: dirección de salida desde la que comienza y termina cada jornada
Proceso de cálculo — 5 pasos
1

Geocodificación — convertir direcciones en coordenadas GPS

Cada dirección de cliente se convierte automáticamente en coordenadas de latitud y longitud. Los resultados se almacenan en caché para evitar consultas repetidas. Los clientes sin coordenadas válidas se excluyen del planning con aviso.

2

Agrupación geográfica (clustering) Fase 1

Los clientes se agrupan en zonas geográficas usando un algoritmo de clustering jerárquico por enlace completo: cada grupo tiene un diámetro máximo de 2,5 km, garantizando que todos los clientes de un grupo están cerca entre sí.

3

Asignación de grupos a días (bin-packing) Fase 2

Los grupos se asignan a días laborables respetando las horas máximas de jornada. No se mezclan grupos cuyo centro geográfico esté a más de 8 km — cada día de trabajo cubre una zona compacta del territorio.

4

Orden óptimo de visitas — TSP Fase 3

Para cada día, se calcula el orden de visita que minimiza el tiempo total de desplazamiento. Con hasta 12 clientes por día se usa Held-Karp (solución exacta al Problema del Viajante). Para días con más clientes, se aplica el algoritmo 2-opt que mejora iterativamente la ruta.

5

Tiempos reales de conducción Google Maps

Calculado el orden óptimo, se consulta la API de Google Maps Distance Matrix para obtener los tiempos reales de conducción entre cada par de clientes, teniendo en cuenta el tráfico y las carreteras reales. El sistema también detecta qué clientes están a menos de 600 m para ir andando y así evitar desplazamientos en coche innecesarios.

Herramientas de cálculo de distancias
Principal
Google Maps Distance Matrix API
Tiempos reales de conducción entre cada par de clientes, considerando carreteras reales y tráfico
Alternativa
OpenRouteService (ORS)
API de rutas de conducción como alternativa cuando Google Maps no está disponible
Respaldo matemático
Fórmula de Haversine × 1,40
Distancia en línea recta corregida con un factor de tortuosidad viaria. Se usa si ambas APIs fallan
Optimización
Held-Karp + 2-opt
Algoritmos de optimización combinatoria para calcular el orden de visita que minimiza el recorrido total
Resultado: Un planning semanal con los clientes asignados a cada día en el orden de visita óptimo, con horas estimadas de llegada y salida para cada uno. Se guarda automáticamente en la nube y queda disponible en la app al instante — sin intervención manual.
